# 🗓️ Cohort Schedule & How the 4 Weeks Run

This program runs as **monthly cohorts** — a new batch starts each month. This file explains how a cohort flows week by week, how the live class works, and what you must do each week.

> 📌 **Your cohort:** `[Month YYYY] Cohort` — exact class date & time are shared in the [WhatsApp group](https://chat.whatsapp.com/JvShK68sncb4IreV26k4sJ) once you enroll.

---

## 🟢 How the live class works
- **One live class per week (~1.5–2 hours)** on **Google Meet.** The joining link is posted in the WhatsApp group before each class.
- Each weekly class covers that week's **three sessions** (topic blocks) — see [`CURRICULUM.md`](CURRICULUM.md).
- **Some classes may be in person** at a Bangalore location where feasible — mentors will announce these in advance.
- **Recordings:** if a class is recorded, the link is shared in the WhatsApp group for revision (where available).
- **Mentor team:** Manish Kumar, Gowrishankar, Kesavan, Mamtha, Srinivas, Manoj, and Sunil support the cohort as a shared team.

## 📅 The 4-week flow

### ⭐ Day 0 — Onboarding (before Week 1)
- [ ] Complete enrollment & payment — see [`ENROLLMENT-AND-ONBOARDING.md`](ENROLLMENT-AND-ONBOARDING.md)
- [ ] Join the **WhatsApp group**
- [ ] **Add the internship to your LinkedIn profile** (script in [`WEEKLY-SCRIPTS.md`](WEEKLY-SCRIPTS.md))
- [ ] Post your **"I've joined"** announcement (tag CBC + all 7 mentors)
- [ ] Install tools: Git, VS Code, Docker Desktop, `kubectl`, Azure CLI + create GitHub, Docker Hub & Azure accounts ([`CONTRIBUTING.md`](CONTRIBUTING.md))

### 📘 Week 1 — Linux, Shell & Docker Foundations
- **Live class:** Sessions 1–3 (Linux & shell scripting · Git & GitHub · Docker fundamentals)
- **Assignment:** Create and deploy your own Dockerized application (push image to Docker Hub)
- **By end of week:**
  - [ ] Attend the live class
  - [ ] Complete the Week-1 assignment
  - [ ] **Post #1 (Week 1)** on LinkedIn + **Video #1** on LinkedIn & Instagram

### 📗 Week 2 — Kubernetes & Monitoring
- **Live class:** Sessions 1–3 (Kubernetes core · config/networking/scaling · monitoring introduction)
- **Assignment:** Deploy a multi-tier application to Kubernetes
- **By end of week:**
  - [ ] Attend the live class
  - [ ] Complete the Week-2 assignment
  - [ ] **Post #2 (Week 2)** + **Video #2**

### 📙 Week 3 — Azure & CI/CD
- **Live class:** Sessions 1–3 (Azure fundamentals · AKS · Azure DevOps & CI/CD)
- **Assignment:** Create a complete CI pipeline (build → ACR → AKS)
- **By end of week:**
  - [ ] Attend the live class
  - [ ] Complete the Week-3 assignment
  - [ ] **Confirm your assigned DevOps capstone with your mentors** and check you're listed in [`PROJECTS-CATALOG.md`](PROJECTS-CATALOG.md)
  - [ ] **Post #3 (Week 3)** + **Video #3**
  - [ ] 💳 Delete/stop your Azure lab resources to keep costs minimal

### 📕 Week 4 — DevOps Capstone & Demo Day
- **Build:** develop your assigned project in your own repo folder, with mentor check-ins — Dockerize → Azure CI/CD → deploy to AKS → monitoring
- **Deliverables:** GitHub repo + project documentation + 3–5 min demo video + final presentation
- **Demo Day:** present your project live (demo + Q&A)
- **By end of week:**
  - [ ] Push your capstone to `interns/Your-Name/` and fill its README
  - [ ] **Capstone post** (with GitHub link) + **Demo video**
  - [ ] Present on Demo Day
  - [ ] Confirm all links are in your `SUBMISSIONS.md`

### 🎓 After Week 4 — Certification
- Mentors verify your attendance, posts, videos, and capstone, then issue your **verifiable certificate** — see [`CERTIFICATE-CRITERIA.md`](CERTIFICATE-CRITERIA.md).
