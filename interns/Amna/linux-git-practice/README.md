## Bash Scripts

This repository contains the following Bash scripts:

### 1. student_info.sh

This script accepts the user's Name, College, and Course as input and displays the entered information.

Run command:

```bash
./scripts/student_info.sh
```

### 2. even_odd.sh

This script accepts a number from the user and checks whether it is even or odd.

Run command:

```bash
./scripts/even_odd.sh
```

### 3. file_exist.sh

This script accepts a filename from the user and checks whether the file exists.

Run command:

```bash
./scripts/file_exist.sh
```

## How to Run the Scripts

First, give execute permission to the scripts:

```bash
chmod +x scripts/*.sh
```

Then run any script using:

```bash
./scripts/script_name.sh
```

Example:

```bash
./scripts/even_odd.sh
```
