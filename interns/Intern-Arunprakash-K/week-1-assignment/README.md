# Week 1 — DevOps Assignment

Beginner Bash shell scripting exercises for Week 1 of a DevOps learning track.

## Scripts

- **`demo.sh`** — Prints special shell variables (`$0`, `$1`, `$#`, `$@`, `$*`, `$$`, `$?`) and shows command exit statuses.
- **`new.sh`** — Prompts for name, age, and department, then displays them.
- **`num.sh`** — Reads a number and checks if it's positive, negative, or zero using `if / elif / else`.

The scripts live in both the `shell-scripts/` and `careerbytecode/` folders.

## How to Run

```bash
git clone https://github.com/arunprakash432/week1-devops-assignment.git
cd week1-devops-assignment/shell-scripts

bash demo.sh hello world
bash new.sh
bash num.sh
```

**Requires:** Bash (Linux/Unix, WSL, or Git Bash on Windows).
