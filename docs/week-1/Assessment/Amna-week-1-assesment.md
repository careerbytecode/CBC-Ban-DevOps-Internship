## Questions

### Q1.
What is Linux? Explain any five advantages of using Linux.

### Q2.
Explain the difference between Open Source Software and Proprietary Software with suitable examples.

### Q3.
Write the Linux commands to perform the following tasks:
- Create a directory named `training`
- Create two files inside it
- Display all files
- Rename one file
- Delete the other file

### Q4.
Explain the purpose of the following Linux commands with one example each:
- `clear`
- `whoami`
- `date`
- `cal`
- `history`

### Q5.
Write Linux commands to perform the following:
- Display the current date and time
- Display the current logged-in user
- Display the current working directory
- Create a new folder named `project`
- Create an empty file named `demo.txt`

### Q6.
Research any **three Linux commands** that were not covered during the training and explain their purpose with an example.

### Q7.
Explain the purpose of the following Linux directories:
- `/home`
- `/etc`
- `/var`
- `/usr`
- `/tmp`

### Q8.
What are Linux file permissions? Explain **Read**, **Write**, and **Execute** permissions with suitable examples.

### Q9.
Suppose you are unable to edit a file because of permission issues. Which commands would you use to identify and resolve the problem?

### Q10.
What steps would you follow if you accidentally forgot the location of a file in your Linux system?

### Q11.
What is Git? Explain why version control is important in software development.

### Q12.
Write the Git commands to perform the following:
- Initialize a Git repository
- Add a file
- Commit the changes
- Check the repository status
- View the commit history

### Q13.
Research any **three Git commands** that were not covered during the training and explain their purpose.

### Q14.
What is GitHub? Explain the difference between **Git** and **GitHub**.

### Q15.
Explain the purpose of the following GitHub features:
- Repository
- Branch
- Clone
- Commit
- Pull Request

### Q16.
Write a Bash shell script that accepts your **Name**, **College**, and **Course** as input and displays the entered information.

### Q17.
Write a Bash shell script to check whether a given number is **Even** or **Odd** and display an appropriate message.

### Q18.
Write a Bash shell script that accepts a filename from the user and checks whether the file exists. If the file exists, display **"File Found"**; otherwise, display **"File Not Found"**.

### Q19.
Research any **two DevOps tools** that work along with Linux and Git. Explain what they are used for and why they are popular.

### Q20.
