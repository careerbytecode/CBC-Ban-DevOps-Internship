## Questions

### Q1.
Explain the architecture of Linux with a neat diagram and describe the role of the Kernel, Shell, User Space, and Hardware.

### Q2.
Differentiate between Linux and Unix by listing at least eight differences.

### Q3.
Write the Linux commands to perform the following tasks:
- Create a directory named `careerbytecode`
- Create three files inside it
- Rename one file
- Copy one file
- Delete one file
- Display the current working directory

### Q4.
Explain the purpose of the following commands with one example each:
`pwd`, `ls`, `cd`, `mkdir`, `touch`, `cp`, `mv`, and `rm`.

### Q5.
Write Linux commands to search for a file, count the number of files in a directory, display hidden files, and display the first 10 lines of a file.

### Q6.
Research and explain five Linux commands that were not covered during the training. Include one example for each.

### Q7.
Explain the purpose of the following Linux directories:
`/home`, `/etc`, `/var`, `/usr`, `/opt`, `/tmp`, `/boot`, and `/dev`.

### Q8.
Differentiate between numeric and symbolic file permissions with suitable examples using `chmod`.

### Q9.
Your Linux server is running slowly. List the commands you would use to identify the problem and explain why you selected them.

### Q10.
A user cannot access a file stored in the server. Describe the troubleshooting steps you would follow.

### Q11.
Explain the complete Git workflow from creating a repository to pushing code to GitHub.

### Q12.
Write the Git commands required to initialize a repository, add files, commit changes, create a branch, merge it, and push the code.

### Q13.
Research any three Git commands that were not discussed during the training and explain their purpose.

### Q14.
What is GitHub? Explain Repository, Clone, Fork, Pull Request, and Issues.

### Q15.
Explain how GitHub helps multiple developers work on the same project without losing each other's changes.

### Q16.
Write a Bash shell script that accepts a user's name, age, and department as input and displays the entered information.

### Q17.
Explain the purpose of the following Bash special variables with examples:
`$0`, `$1`, `$2`, `$#`, `$?`, `$$`, `$@`, and `$*`.

### Q18.
Write a shell script to determine whether a number is positive, negative, or zero using `if`, `elif`, and `else`.

### Q19.
Research three open-source DevOps tools that work well with Linux and Git. Explain their purpose and one real-world use case for each.

### Q20.
Create a GitHub repository named **week1-devops-assignment** containing:
- A README file
- Linux command practice
- One Bash shell script
- At least five Git commits
- Screenshots of the executed commands
