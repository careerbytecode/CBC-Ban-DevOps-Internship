## Questions

### Q1.
What is Linux? Explain why it is widely used in servers and cloud environments.

### Q2.
Explain the difference between the Command Line Interface (CLI) and the Graphical User Interface (GUI). Which one is preferred by DevOps Engineers and why?

### Q3.
Write the Linux commands to perform the following tasks:
- Create a directory named `DevOpsTraining`
- Create three files inside the directory
- Copy one file
- Rename another file
- Display all files in long listing format

### Q4.
Explain the purpose of the following Linux commands with one example each:
- `ls`
- `pwd`
- `cd`
- `history`
- `clear`

### Q5.
Write Linux commands to:
- Display the current user
- Display today's date
- Create a directory named `scripts`
- Create a file named `test.sh`
- Remove the file `test.sh`

### Q6.
Research any **three Linux commands** that you think are useful for beginners and explain their purpose with examples.

### Q7.
Explain the purpose of the following Linux directories:
- `/etc`
- `/usr`
- `/tmp`
- `/home`
- `/root`

### Q8.
What is the difference between a **relative path** and an **absolute path**? Explain with suitable examples.

### Q9.
Suppose you cannot find a file that you created yesterday. Which Linux command(s) would you use to locate it? Explain your answer.

### Q10.
What command would you use to check the permissions of a file? How would you give read and write permission to the file owner?

### Q11.
What is Version Control? Explain how Git helps developers manage project changes.

### Q12.
Write the Git commands to perform the following:
- Configure Git username and email
- Initialize a repository
- Add all files
- Commit the changes
- Check the repository status

### Q13.
Research any **three Git commands** that were not discussed during the training and explain their purpose with simple examples.

### Q14.
What is GitHub? Explain the purpose of the following:
- Repository
- Clone
- Branch
- Commit
- Pull Request

### Q15.
Why is a README.md file important in every GitHub repository? Mention at least five points.

### Q16.
Write a Bash shell script that accepts your **Name**, **College**, and **Branch** as input and displays the details in a formatted output.

### Q17.
Write a Bash shell script to check whether a given number is **Positive**, **Negative**, or **Zero**.

### Q18.
Write a Bash shell script using a **for loop** to display the numbers from **1 to 20**.

### Q19.
Research any **two DevOps tools** that were not covered during the training. Explain what they are used for and why organizations use them.

### Q20.
