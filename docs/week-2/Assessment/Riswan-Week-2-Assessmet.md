## Questions

### Q1.
What is Docker? Explain why it is widely used in server and cloud environments.

### Q2.
Explain what containerization is and how it improves application portability across different environments.

### Q3.
Explain the Docker architecture and how the daemon, client, images, and containers work together.

### Q4.
Write the Docker commands to perform the following:
- Build an image named `app:latest` from the current directory
- Run it as a container mapping port 3000 to 3000
- Inspect the container details
- Copy a file from the container to the host
- Stop and remove the container

### Q5.
Explain the purpose of the following Dockerfile instructions with examples:
- `FROM`
- `RUN`
- `EXPOSE`
- `ENV`
- `ENTRYPOINT`

### Q6.
What is a Docker **Volume**? Write the commands to create a named volume and attach it to a container.

### Q7.
Explain the different **Docker network types** and when you would use each.

### Q8.
Write a `docker-compose.yml` file that runs a web application together with a database, and explain the file.

### Q9.
Research any **three Docker troubleshooting scenarios** (for example, a build failure or containers unable to communicate) and explain how you would resolve them.

### Q10.
What is Kubernetes, and why is it needed for managing containers at scale in production?

### Q11.
Explain the Kubernetes **Control Plane** components (API Server, etcd, Scheduler, Controller Manager) and what each one does.

### Q12.
Write a **Pod** manifest for an `nginx` container and the commands to create it, describe it, and view its logs.

### Q13.
Write a **Deployment** manifest with 3 replicas and explain how you would scale it up to 5 replicas using a command.

### Q14.
Explain the difference between **ClusterIP**, **NodePort**, and **LoadBalancer** Services with a use case for each.

### Q15.
Explain how **ConfigMaps** are used to store configuration data and how they are consumed inside a Pod.

### Q16.
What is a **StatefulSet**, and why is it required for stateful applications such as databases?

### Q17.
Explain how the **Horizontal Pod Autoscaler (HPA)** scales Pods automatically and what metrics it relies on.

### Q18.
Set up **Minikube**, deploy a Deployment and expose it with a Service, then access the application. Write all the commands and attach screenshots.

### Q19.
Research any **three `kubectl` commands** not covered during the training and explain their purpose with examples.

### Q20.
Create a GitHub repository named **week2-devops-k8s** and upload:
- A Dockerfile and the image pushed to a registry (include the link)
- A Deployment, Service, and ConfigMap manifest
- A `README.md` documenting your work
- At least five Git commits
- Screenshots of the running application on Minikube
