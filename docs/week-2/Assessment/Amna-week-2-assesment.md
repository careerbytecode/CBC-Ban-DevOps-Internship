## Questions

### Q1.
What is Docker? Explain any five benefits of using Docker in a DevOps workflow.

### Q2.
What is containerization? Explain how it differs from traditional application deployment.

### Q3.
Explain the difference between a **Virtual Machine** and a **Docker Container** with at least five points.

### Q4.
Explain the Docker architecture and describe the role of the following components:
- Docker Client
- Docker Daemon
- Docker Image
- Docker Container
- Docker Registry

### Q5.
Write the Docker commands to perform the following tasks:
- Pull the `nginx` image
- List all images
- Run a container from the `nginx` image
- List all running containers
- Stop and remove the container

### Q6.
What is a **Docker Image**? Explain the difference between an **image** and a **container** with a suitable example.

### Q7.
What is a **Dockerfile**? Write a simple Dockerfile that runs a basic Python or Node.js application.

### Q8.
Explain the purpose of the following Dockerfile instructions with one example each:
- `FROM`
- `WORKDIR`
- `COPY`
- `RUN`
- `CMD`

### Q9.
What are **Docker Volumes**? Explain why they are needed and write the command to create and mount a volume.

### Q10.
Research any **three Docker commands** that were not covered during the training and explain their purpose with an example.

### Q11.
What is Kubernetes? Explain any five reasons why organizations use Kubernetes to manage containers.

### Q12.
Explain the Kubernetes architecture and describe the role of the following components:
- API Server
- etcd
- Scheduler
- Kubelet
- Kube-proxy

### Q13.
What is a **Pod** in Kubernetes? Write a simple Pod YAML manifest that runs an `nginx` container.

### Q14.
Install **Minikube** on your machine and write the commands to:
- Start the cluster
- Check the cluster status
- View all nodes
- View all pods
(Attach screenshots.)

### Q15.
What is a **Deployment** in Kubernetes? Explain how it is different from a Pod.

### Q16.
Explain the three main types of Kubernetes **Services** — ClusterIP, NodePort, and LoadBalancer — with a use case for each.

### Q17.
What is a **ConfigMap** and a **Secret**? Explain the difference between them with an example.

### Q18.
Research any **two Kubernetes commands** (`kubectl`) that were not covered during the training and explain their purpose.

### Q19.
Explain what **Grafana** is used for and how it helps in monitoring a Kubernetes cluster.

### Q20.
Create a GitHub repository named **docker-kubernetes-practice** and upload the following:
- One Dockerfile
