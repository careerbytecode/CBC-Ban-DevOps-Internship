## Questions

### Q1.
What is Docker, and why has it become one of the most preferred tools for DevOps Engineers?

### Q2.
Explain the concept of **containerization** and why it is important for building and shipping modern applications.

### Q3.
Describe the flow of how the **Docker Client**, **Docker Daemon**, and **Docker Registry** interact when you run `docker run nginx`.

### Q4.
Write the Docker commands to perform the following:
- Display the Docker version
- Pull the `ubuntu` image
- Run an interactive Ubuntu container
- Display all containers (running and stopped)
- Remove all stopped containers

### Q5.
Explain the difference between the `COPY` and `ADD` instructions in a Dockerfile.

### Q6.
Write a Dockerfile that installs and runs a simple application, then explain how you would build and run it.

### Q7.
Why do we need **Docker Volumes**? Explain what happens to container data when a container is deleted without a volume.

### Q8.
What is **Docker Compose** and why is it useful when working with multiple containers?

### Q9.
Research any **three real-world use cases** of Docker in companies and explain them briefly.

### Q10.
Why do we need **Kubernetes**? Explain the problems it solves that Docker alone cannot.

### Q11.
Explain the role of the following Kubernetes components:
- Control Plane
- Worker Node
- kubelet
- Scheduler
- Controller Manager

### Q12.
What is a **Pod**? Explain why Kubernetes uses Pods instead of directly running containers.

### Q13.
Write a **Deployment** manifest for an `nginx` application with 2 replicas, and explain how Kubernetes maintains the desired number of Pods.

### Q14.
A Pod is running but you cannot access the application from outside the cluster. Which **Service** type would you use and why? Write the manifest.

### Q15.
Explain how you would store a database password securely in Kubernetes and inject it into a Pod.

### Q16.
What is an **Ingress**, and in what situation would you choose it over a LoadBalancer Service?

### Q17.
Your application receives sudden high traffic. Explain how the **Horizontal Pod Autoscaler** would help and what it needs to work.

### Q18.
Install **Minikube** and deploy any application to it. Write the commands you used and attach screenshots of the running Pods.

### Q19.
Research and explain how **Grafana** dashboards help teams monitor the health of applications running on Kubernetes.

### Q20.
Create a GitHub repository named **week2-container-orchestration** and upload:
- A Dockerfile
- A Deployment and a Service YAML manifest
- A `README.md` explaining the scenario you solved
- At least five Git commits
- Screenshots of your Minikube deployment
