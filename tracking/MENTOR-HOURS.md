# ⏱️ Mentor Hours Log

A running log of every mentoring class/session, kept by the mentor team. It shows students the **real contact time** behind this program, and feeds the **total hours on your certificate**.

> 🤖 **Keep the table format exactly as below** (same columns, `|`-separated) — the leaderboard script reads this file to compute each student's total sessions & hours.

### How to log a session
- Add **one row per class/session**.
- **Session Type:** `Group Live` · `1:1` · `Capstone Review` · `In-person`
- **Students Present:** write `ALL` for a whole-cohort class, or list names separated by `;` for specific students (e.g. `Aarav S; Meera K`).
- **Duration (mins):** session length in minutes.

> 📌 This program runs **one ~2-hour live class per week** (Weeks 1–3) plus Demo Day in Week 4, with optional 1:1 / capstone-review sessions.
